# 왕전초 연산왕 (Wangjeon Math King)

초등학생이 연산 기호를 넣어 식을 완성하는 연산 퍼즐 게임입니다.
`+`, `-`, `×`, `÷` 버튼을 눌러 빈칸을 채우고 목표 숫자를 만들면 됩니다.

**바로 플레이:** https://chohanui2-home.github.io/wangjeon-math/

## 특징

- **6단계** — 1단계 워밍업부터 6단계 왕전초 연산왕까지, 화면 맨 아래 탭으로 바로 이동
- **단계마다 연산 버튼이 다르다** — 1단계는 더하기(`+`)·빼기(`-`)만 보이고, 2단계에서 `×`, 3단계부터 `÷`까지 나타납니다. 1단계 140문제는 모두 `+`·`-` 경로로만 목표 숫자에 닿습니다.
- **한 판 5문제** — 단계별 제한시간 60~90초, 일시정지·재도전 가능
- **840문제** — 단계마다 140문제, 매번 중복 없이 랜덤 출제
- **정답이 여러 개인 문제도 정답** — 저장된 한 가지 답과 비교하지 않고, 표준 계산 순서(×, ÷ 먼저)로 실제 계산해서 판정합니다
- **음수 없음** — 모든 문제는 계산 중간에 0보다 작은 수가 나오지 않습니다(초등 저학년 눈높이). 나눗셈은 항상 딱 떨어지는 경우만 나옵니다
- **혼자서도 재미있게** — 귀여운 마스코트 표정 변화, 별·폭죽 효과, 효과음(음소거 가능)
- **기록 저장** — 단계별 최고 점수와 별점을 브라우저에 저장
- **이번 단계 점수 + 누적 점수** — 상단 상태바·결과 화면에 둘 다 나란히 나옵니다. `다음 단계`로 이어 풀면 누적이 계속 쌓이고, 같은 단계를 `다시 풀기` 하면 그 단계 점수만 최신 점수로 바뀌어 점수가 부풀지 않습니다
- **🏆 기록 남기기(플레이 중에도)** — 상단 `🏆 기록` 버튼을 누르면 지금까지의 `이번 단계 점수 · 누적 점수 · 맞힌 문제`가 담긴 기록창이 열립니다. 기록을 남긴 뒤 닫으면 그 자리에서 계속 풀 수 있습니다(창을 연 동안 시간은 멈춤)
- **공용 태블릿** — 결과 화면(또는 누적이 쌓인 뒤 상단)의 `↻ 새 도전자`를 누르면 누적 점수를 지우고 1단계부터 새로 시작합니다
- **친구에게 공유** — 결과 화면의 공유 버튼(휴대폰 공유 시트 / 링크 복사)
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱처럼 열립니다

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일. 외부 CDN·폰트·이미지 0개(모든 그림은 인라인 SVG, 소리는 Web Audio API). 파일 하나만 보내도 그대로 열립니다.
- `app_template.html` — 빌드용 템플릿(문제 데이터 자리표시자 포함)
- `build.py` — 문제 은행 생성·전수 검증 후 `index.html`을 만드는 스크립트
- `test_app.py` — QuickJS로 게임 스크립트를 실행해 계산기·문제 은행·화면 흐름을 검사하는 테스트

## 다시 빌드하기

```bash
python3 build.py      # 문제 840개 전수 검증 후 index.html 생성
python3 test_app.py   # 테스트 (quickjs 파이썬 모듈 필요)
```

`build.py`는 다음을 전부 확인합니다.

- 모든 문제가 실제로 풀리는지(모든 연산 조합 전수 계산)
- 나눗셈이 정수로 떨어지고 0으로 나누지 않는지
- 목표 숫자에 도달하는 풀이 중 **계산 중간값이 음수인 경우가 없는 풀이가 최소 하나** 있는지
- 목표 숫자가 1 이상 자연수인지

## 만든 방식

문제는 숫자와 연산자를 무작위로 뽑아 표준 계산 순서로 계산하고, 그 결과를 목표 숫자로 삼아 만듭니다.
그래서 문제를 낼 때는 정답이 하나로 정해져 있지 않아도, 채점할 때는 학생이 넣은 연산자를 그대로 계산해 목표 숫자와 같은지 봅니다.
